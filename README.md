# Rastgele Felsefi Bardak Sözleri

Bu proje, insanlığın en büyük sorularından birine cevap arar: "Bir bardak ne düşünür?"

Cevap: Rastgele felsefi şeyler.

## Nasıl Çalışır?

```bash
python bardak.py
```

Her çalıştırışta yeni bir derin, anlamsız, ama çok ciddi görünen söz üretir. Belki de hayatın anlamı budur.

## Neden?

Çünkü herkes AI ile ciddi şeyler yapıyor. Biz bardaklarla felsefe yapıyoruz.
